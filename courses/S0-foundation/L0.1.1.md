# L0.1.1｜高精人物到底在做什么

> 阅读时间：约 5 分钟  
> 实践时间：约 15–30 分钟

## 本课目标

建立一个最重要的认知：

**高精人物不是“把一个模型越雕越细”，而是一条分阶段解决不同问题的生产管线。**

如果一开始不知道整条 Pipeline，后面很容易出现：

- 大形还没对，就开始刻毛孔
- Sculpt 做完才发现拓扑无法继续
- 材质很复杂，但人物仍然不像真人
- 头发、灯光、皮肤同时学，无法判断问题来自哪里

本课不要求你打开 Blender 做复杂操作，只要求先建立地图。

---

# 1. 一张图理解人物生产流程

课程后续基本沿着这条路径前进：

```text
Reference
   ↓
Blockout / Primary Form
   ↓
Sculpt / Secondary Form
   ↓
Likeness / Anatomy
   ↓
Retopology
   ↓
UV
   ↓
Multires / High-frequency Detail
   ↓
Bake
   ↓
Texture / Skin Shader
   ↓
Eyes / Teeth
   ↓
Hair Groom
   ↓
Clothing
   ↓
Camera / Lighting
   ↓
Cycles Render
```

每一步都在解决不同的问题。

---

# 2. Sculpt：解决“这个人是什么形状”

Sculpt 的任务不是制造毛孔。

前期最重要的是：

- 头有多宽
- 头有多长
- 颧骨在哪里
- 下颌是什么角度
- 鼻子伸出来多少
- 眼眶有多深
- 脑颅和面颅是什么关系

这些被称为 **Primary Form / Secondary Form**。

一个只有灰色材质、没有皮肤和头发的模型，如果大形正确，通常已经能明显像一个具体的人。

反过来，一个脸型错误的模型，即使有 8K 皮肤、毛孔和头发，也只会变成“很真实的错误人物”。

---

# 3. Retopology：解决“这个模型能不能被继续使用”

自由雕刻时，Mesh 往往只服务于塑形。

它可能：

- 面数巨大
- Edge Flow 混乱
- 局部密度完全不同
- 不适合 UV
- 不适合变形

Retopology 是在高模表面重新建立一个干净的 Production Mesh。

简单理解：

```text
Sculpt Mesh = 雕塑
Production Mesh = 可继续生产的数字模型
```

课程到 S4 才会系统学习它。

现在只需要知道它为什么存在。

---

# 4. UV：解决“二维图片怎么贴到三维模型上”

皮肤颜色、粗糙度等很多信息最终是二维 Texture。

UV 的作用就是建立：

```text
3D Surface
     ↕
2D Texture
```

之间的对应关系。

可以把它想象成把一个纸质地球仪剪开、摊平。

---

# 5. Texture / Shader：解决“表面是什么材料”

人物皮肤不是一个粉色材质。

真实皮肤通常涉及：

- Base Color
- Roughness
- Normal
- Displacement
- SSS（Subsurface Scattering）

它们分别描述：

```text
颜色
反光程度
微小方向变化
真实表面起伏
皮下散射
```

这里的关键认知仍然是：

**材质让正确的模型变真实，不负责把错误的模型变正确。**

---

# 6. Groom：解决毛发，而不是“贴一块头发”

写实头发需要考虑：

- 发型大轮廓
- Guide Curves
- 大束 Clump
- 中束
- 碎发
- 发际线
- 眉毛
- 睫毛
- Peach Fuzz

因此 Hair 本身就是一个独立系统。

本课程会后置到 S6。

原因很简单：早期加入头发，会严重干扰你判断头骨和脸型。

---

# 7. Lighting：不是救模型，而是暴露模型

好的肖像灯光应该帮助观察：

- 额头转折
- 眼眶深度
- 鼻子体积
- 颧骨
- 下颌

学习阶段我们会故意使用比较中性的灯光。

如果一个模型只有在某一个漂亮角度、某一种强烈灯光下才好看，通常说明结构还没有真正成立。

---

# 8. 你现在最需要记住的一句话

整个课程会反复强调：

```text
Shape First.
Detail Later.
```

对应中文就是：

> **先解决形，再解决细节。**

高精度并不等于高面数，也不等于毛孔数量。

真正的高精人物，是在正确的大形上，逐层建立越来越高频的信息。

不要求漂亮，可以使用 Mermaid、Excalidraw、纸笔、Markdown 或任何工具。

至少包含：

1. Reference
2. Sculpt
3. Retopology
4. UV
5. Detail / Bake
6. Texture / Skin
7. Hair
8. Lighting / Render

然后在每一步旁边，用**一句自己的话**写：

> 这一步到底解决什么问题？

# 判断标准

## PASS

满足全部：

- 能按正确逻辑描述完整 Pipeline
- 能说清 Sculpt / Retopo / UV / Texture / Groom / Render 的角色区别
- 明确 Primary Form 的优先级高于毛孔等 Micro Detail
- 三个问题都能用自己的话解释

## REVISE

出现任一：

- 把 Retopology 理解成“让模型更精细”
- 把 UV 理解成材质本身
- 认为高精度人物主要依赖毛孔、8K Texture 或高面数
- 无法解释为什么课程前期故意禁止皮肤、毛发和复杂灯光
