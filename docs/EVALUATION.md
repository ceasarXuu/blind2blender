# Blind2Blender 统一验收体系

## 总原则

评价优先级：

```text
1. 结构正确性
2. 比例与轮廓
3. 观察与解释能力
4. 技术实现
5. 完成度
6. 微细节
```

高精人物课程不允许用“细节很多”替代“结构正确”。

---

## 通用评分维度

每项 0–2 分：

| 分值 | 含义 |
|---|---|
| 0 | 明显不成立 / 未完成 |
| 1 | 基本方向正确，但存在影响结果的问题 |
| 2 | 达到当前阶段要求 |

### A. 目标完成度
是否真正完成本课要求，而不是做了相邻内容。

### B. 形体 / 技术正确性
根据课程类型判断结构、拓扑、材质或流程是否正确。

### C. 多视角稳定性
模型不能只在一个角度成立。

### D. 可解释性
能否说明为什么这样做，以及问题在哪里。

### E. 交付完整度
文件、截图、说明是否足以完成 Review。

满分 10 分。

建议：

- `9–10`：PASS
- `7–8`：PASS，但记录改进项
- `≤6`：REVISE

但存在 **Critical Failure** 时，无论总分多少都不能 PASS。

---

## Critical Failure

以下问题属于结构性失败：

### Sculpt / Anatomy
- 仅单一角度成立，其他角度明显崩坏
- 基础比例明显错误却进入微细节
- 使用毛孔、头发、灯光掩盖大形问题
- 关键解剖关系与人体结构冲突

### Retopology
- 大量非预期穿插
- 关键区域无法继续 Subdivision / Bake
- 明显错误法线或破面未处理

### UV / Bake
- 关键区域严重拉伸
- 非预期 UV 重叠
- 大片投射错误、爆点、接缝未处理

### LookDev
- Skin Shader 依赖异常强灯光才成立
- 眼球悬空或穿插
- 微细节尺度明显错误

### Final
- 明显穿模
- 主视角结构错误
- 最终图依赖后期改变模型身份特征

---

## Review 输出格式

每次 Review 尽量限制为：

```text
状态：PASS / REVISE
得分：x / 10

证据：
- ...
- ...

最高优先级问题：
1. ...
2. ...
3. ...

下一轮验证：
- ...
```

如果是 REVISE，优先只给 1–3 个最高价值修改项，避免初学阶段被大量次要反馈淹没。

## Stage Gate 评价

Stage Gate 不直接沿用单课 10 分制，而检查该阶段核心能力是否形成。

### S0 Gate
- Blender 基本导航无需查教程
- 能从 Sphere 进入 Sculpt
- 会使用核心 Brush
- 理解 Remesh 与 Symmetry

### S1 Gate
- 正 / 侧 / 3/4 均成立
- Silhouette 成立
- 男 / 女 / 老年人头能体现结构差异
- 没有依赖微细节

### S2 Gate
- 300–500 px 缩略图仍有明显 Likeness
- 能指出参考人物 5 个高优先级身份特征
- 能区分焦距问题与模型问题

### S3 Gate
- 人体比例合理
- 胸腔 / 骨盆关系成立
- 手脚不是占位符
- Pose 存在重心

### S4 Gate
- Retopo / UV / Bake 流程可稳定复现
- 高低模职责清楚
- 无关键生产阻塞

### S5 Gate
- 灰度材质下模型仍成立
- Skin / Eye / Micro Detail 尺度合理
- 材质没有掩盖结构错误

### S6 Gate
- Hair / Clothing / Camera / Lighting 形成完整 LookDev
- 灯光服务结构表达
- 最终渲染无明显技术问题

### S7 Gate
- 完成公开展示级静帧
- Breakdown 完整
- 能主动识别问题并说明主要技术与艺术决策
